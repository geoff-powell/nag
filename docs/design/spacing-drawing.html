NOTES:(UNLESS OTHERWISE SPECIFIED)
  1. Do not scale from screen. Read the numbers.
  2. All dimensions in points at 1×. System list, form and window insets are not ours and are drawn as phantom lines.
  3. Slots are placeholders. Text, icons and copy are not part of the drawing.
 
  1. Every dimension is a variable (S#, Z#, R#). S0–S6 map to Space.xxs–Space.xxl; derived values are formulas.
  2. HUG = sized by its content · FLEX = takes the remaining space · FILL = full width of its parent.
  3. R4 (pill) = Capsule, which renders as height ÷ 2.
  4. Grayscale by design. Color is out of scope.
